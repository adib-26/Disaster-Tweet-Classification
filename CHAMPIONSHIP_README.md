# Original Baseline Notes

This file documents the original `championship_solution.py` baseline. It is kept for comparison with the newer sparse, BERTweet, and blended pipelines.

## Approach

`championship_solution.py` builds a classical text-classification ensemble:

- tweet text cleaning
- engineered linguistic and social-media features
- TF-IDF word features
- several linear and probabilistic base models
- a stacking classifier for final predictions

The script writes `championship_submission.csv`.

## Current Status

This baseline is useful as a reference point, but it is no longer the strongest local candidate in the workspace. The more reliable final candidate is generated by combining:

- `bertweet_solution.py`
- `ensemble_probabilities.py`
- `sparse_solution.py`
- `blend_submission.py`

The final validated output is `best_submission.csv`.

## Reproducibility

Install dependencies:

```bash
.venv/bin/pip install -r requirements.txt
```

Run the original baseline:

```bash
.venv/bin/python championship_solution.py
```

## Compliance

The intended workflow uses the provided Kaggle train/test files and out-of-fold validation. It does not rely on leaked test labels or manual labeling of the test set.
